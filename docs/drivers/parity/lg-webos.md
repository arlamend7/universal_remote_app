# LG webOS parity matrix

Phase 0 baseline for migrating `LgDeviceController` to the generic declarative driver runtime. Every row below is the acceptance contract for the migrated driver. Source: `packages/remote_driver_runtime/lib/src/adapters/lg_webos/**` and `lib/src/ssap/**`. Cross-provider summary: [TV API matrix](tv-api.md), [capability audit](../../provider-capability-audit.md). Wire-level goldens for these rows (`packages/remote_driver_runtime/test/parity/lg_webos_parity_test.dart`) are described in the [parity README](README.md).

## Header

| Item | Current behavior |
| --- | --- |
| Provider id | `lg.webos` (`ProviderIdentity.lgWebOs.storageId`); managed package id `lg-webos`, current source release `drivers/providers/lg-webos/1.1.0` (operation `compiled.bindings` only). |
| Protocol | SSAP JSON over WebSocket. Request envelope `{"id":"ur_<n>","type":"request","uri":"ssap://<path>","payload":{…}}`; subscribe `{"id","type":"subscribe","uri","payload":{}}`; unsubscribe `{"id","type":"unsubscribe"}`. Replies `type:"response"`; failure when `type:"error"` or `payload.returnValue == false`. Navigation, keys and pointer use a second text socket (pointer socket) with `key:value\n` frames terminated by a blank line. |
| Transport / ports | Default `wss://<host>:3001` (TLS). Legacy `ws://<host>:3000` only when the saved device opted in (`allowInsecure=true`, set by manual "legacy" or "allow insecure pointer"). Pointer socket URL comes from `getPointerInputSocket` (`socketPath`), must be `ws`/`wss` on the same host, no userinfo/fragment; `ws` pointer needs `allowInsecure`. Request timeout 8 s, ≤64 pending requests, ≤32 subscriptions, ≤2 MiB frames (larger or malformed JSON terminates the session with `protocol`). |
| Pairing / credential | `register` with `pairingType:"PROMPT"`, `forcePairing:false`, unsigned `defaultLgManifest` (14 permissions: CONTROL_AUDIO, CONTROL_INPUT_TV, CONTROL_MOUSE_AND_KEYBOARD, CONTROL_POWER, LAUNCH, READ_INSTALLED_APPS, READ_INPUT_DEVICE_LIST, READ_NETWORK_STATE, READ_RUNNING_APPS, READ_CURRENT_CHANNEL, READ_TV_CHANNEL_LIST, CONTROL_INPUT_TEXT, READ_APP_STATUS, CONTROL_INPUT_MEDIA_PLAYBACK). Approval timeout 45 s. Credential = raw `client-key` string, stored through `CredentialStore.write(device.id, key)` → secure-storage key `client-key.v2.<deviceId>`; rewritten after every successful registration. A rejected saved key is deleted (`revokedKey`). |
| Certificate pinning | Optional exact DER pin in metadata `trustedCertificateDer` (base64). With a pin, `IoWebSocketTransport` uses an empty trust store and accepts only that DER for the exact host:port (main and pointer sockets). Without a pin, platform trust applies; a `tls` failure on a `wss` endpoint offers certificate review. Unicast probe compares the presented DER to the pin (450 ms). No global TLS bypass. |
| Device-id formats | Discovery: `lg.webos:<usn-uuid>` (USN before `::`, must start `uuid:`; case preserved), `stableIdentity` true. Manual: `lg.webos:profile:<newProfileId()>` (18 random bytes base64url), `stableIdentity:false`, metadata `identitySource=userProfile`, `pairingState=unpaired`. |
| Reconnection | After an unexpected SSAP close while the user still wants the session: state `reconnecting`, up to 3 retries at 1 s, 2 s, 4 s; counter resets after a successful connect; `disconnect()`/`revokedKey` stop retries. Pointer socket loss only disables navigation/pointer (no reconnect). |
| Wake | Wake-on-LAN magic packet (UDP broadcast, port 9) for metadata `macAddress` (or provider option) to metadata `broadcastAddress` (default `255.255.255.255`). MAC may be manual or learned through `readWakeAddress` (`macAddressSource=television`) or the neighbor resolver (`localNeighbor`). |
| Software identification | After registration: `ssap://com.webos.service.update/getCurrentSWInformation` (8 s, failures ignored). Reads `model_name`, `product_name`, `version`, `sw_type`, `major_ver`, `minor_ver` (non-blank, ≤256 chars) into `raw`. Sets `source=authenticatedSession`, `model=model_name`, `operatingSystem="webOS"`, `firmwareVersion="<major_ver>.<minor_ver>"` only when `sw_type == FIRMWARE`, `identifiedAt`. Unknown: `manufacturer`, `hardwareModel`, `operatingSystemVersion`, `softwareVersion`, `buildNumber`, `protocolVersion`. Legacy metadata `softwareVersion` = `product_name ?? version`. Exposed via `sessionSoftwareInformation` only while connected. |
| webOS integration split | Target folders `lg-webos/webos-legacy` (webOS < 7) and `lg-webos/webos-22-plus` (webOS ≥ 7). The code does **not** derive a webOS version today: `operatingSystemVersion` is never set, `major_ver`/`minor_ver` are firmware numbers, and the only platform-version evidence is the unparsed `raw.product_name` (fixture value `webOSTV 5.0`). The selector must parse `product_name` (assumption to verify on hardware: webOS 22 reports 7.x). No command, payload or capability rule differs by version in the current code, so both integrations start from identical mappings. |
| Release restriction | None beyond the managed package staying outside the publishing index until parity is proven. |

Notation for the table: `*` in a driver path means both `drivers/providers/lg-webos/webos-22-plus/` and `drivers/providers/lg-webos/webos-legacy/` (identical today). **gate(cap)**: throws `unavailable` when the session has no controller for `cap` (not probed, disabled, restricted by profile, or disconnected). **send(cap)**: SSAP request; errors `permission` (text has 401/403/permission), `unsupported` (404/not found/not supported), `command`, `timeout` (8 s), `busy`, `disconnected`, `network`, `protocol`; `permission`/`unsupported` disable `cap` and emit `capabilityChanges`. **query**: same errors, never disables. **pointer**: frame write failure throws `pointer` and disables `navigation` + `pointer`; pointer socket close/error also disables both. Tests are under `packages/remote_driver_runtime/test/adapters/lg_webos/`.

## Provider policies

| Policy | Current behavior |
| --- | --- |
| Manual setup | Label `LG webOS`; advanced setup shown. Endpoint `wss://<ip>:3001` or `ws://<ip>:3000` when "legacy". Address must be a numeric IP, not multicast, loopback, `0.0.0.0`, `::` or `255.255.255.255` (public addresses are accepted). Name required (`name`). Certificate: optional non-empty base64 DER (`certificate`). MAC: optional, validated by `wakePacket`, stored normalized. Broadcast: optional IPv4 (`broadcast`). Metadata `allowInsecure = legacy || allowInsecurePointer`. Changing MAC clears `macAddressSource`/`macAddressLearnedAt`; changing broadcast clears `broadcastAddressSource`. Editing keeps the existing id. Tested by `lg_test.dart` (secure default and manual identities are independent of IP). |
| Network configuration view | address, certificate, MAC, broadcast, legacy (`ws` scheme), allowInsecurePointer (`allowInsecure`). |
| Certificate review | `canReviewCertificate`: error code `tls` and endpoint scheme `wss`. `trustCertificate` writes metadata `trustedCertificateDer`. |
| sameConnection | Equal `trustedCertificateDer`, `allowInsecure`, `macAddress`, `broadcastAddress` (registry also requires same id, provider and endpoints). |
| Retry after wake | Codes `network`, `networkAccess`, `connectionRefused`, `timeout`. |
| mergeDiscovered | Discovered device with saved name; metadata `{...discovered, ...saved}`; endpoint keeps the saved scheme/port with the discovered host. |
| Discovery | SSDP ST `urn:lge-com:service:webos-second-screen:1`; name `friendlyname` or `LG webOS TV`; model `modelname`; all SSDP metadata kept. Address recognition by unicast SSDP probe. Saved-device probe requires a pin and a `wss:3001` endpoint, then compares the presented DER. |
| Wake provider | `canWakeDevice`: provider matches and MAC (metadata or option) normalizes. `wakeDevice`: WoL to metadata/option broadcast; otherwise `wakeUnavailable`. Works without a session. |

## Hardware verification

All rows are fixture-verified only (fake transports and a loopback WebSocket). Check on real LG TVs, at least one webOS < 7 and one webOS ≥ 7:

- `getCurrentSWInformation` field values, especially `product_name` format used to select `webos-legacy` vs `webos-22-plus`, and `sw_type`/`major_ver`/`minor_ver`.
- Registration PROMPT with the unsigned 14-permission manifest; which permissions each firmware grants; revoked-key behavior after "delete connected devices".
- Secure port 3001 certificate presentation and pin stability across reboots and firmware updates; pointer socket scheme and port returned on secure sessions.
- Pointer button names `DASH`, `LIVE_TV`, `CAPTIONS`, `REPLAY`, `SOURCE`, `MUTE`, `INFO`, `GUIDE`, colour keys and `MENU` for settings.
- `media.controls/*` effect in third-party apps; `tv/*` channel commands on non-tuner inputs.
- Screen off/on (`com.webos.service.tvpower`), Bluetooth audio connect/disconnect and the settings `target:"sound"` parameter.
- `connectionmanager/getinfo` and `getStatus`/`getstatus` field names, MAC learning, and Wake-on-LAN from standby with network wake enabled.
- Reconnect after TV standby and network loss (1 s/2 s/4 s retries).
